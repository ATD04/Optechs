# OPTECHS - Cybersecurity & Technical Solutions

A modern, responsive, and content-driven company website built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Next.js App Router**: Modern architecture for optimized performance.
- **TypeScript**: Type-safe development.
- **Tailwind CSS**: Utility-first styling with a custom cybersecurity dark theme.
- **Framer Motion**: Subtle, premium animations for a better user experience.
- **JSON Driven**: All website content is managed via JSON files in `/content`.
- **Fully Responsive**: Mobile-first design for all devices.
- **Modern UI**: Dark navy palette with cyan accents, glassmorphism, and glow effects.

## 📂 Project Structure

- `app/`: Next.js pages and routes.
- `components/`: Reusable UI and layout components.
- `content/`: JSON source for all website content.
- `lib/`: Utility functions and content loaders.
- `types/`: TypeScript interfaces/types.
- `public/`: Assets and images.

## 🛠️ Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The site will be available at [http://localhost:3000](http://localhost:3000).

### Build

```bash
npm run build
```

## 📝 Editing Content

To update the website content, edit the corresponding JSON files in the `/content/` directory:

- `site.json`: Navigation, footer, and branding.
- `company.json`: About us, mission, vision, values, and stats.
- `solutions.json`: Cybersecurity solutions and categories.
- `services.json`: Professional services and processes.
- `vendors.json`: Technology partners and vendors.
- `products.json`: Proprietary security products.
- `support.json`: Support plans and FAQs.
- `contact.json`: Contact information and form configuration.
